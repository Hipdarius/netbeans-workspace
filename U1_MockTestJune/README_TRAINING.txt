U1_MockTestJune

This is now a mock-test starter project.

It intentionally contains only class shells, GUI components, empty button events,
and method signatures. Game.java is also a starter shell. It does not contain Timer
scaffolding or solution comments.

Use the questionnaire in MOCK_TEST_QUESTIONNAIRE.txt or the one pasted in chat.

Priority:
1. H1 CryptoBox: 2D static arrays and file I/O.
2. G4/H2 Angry Balls: base OOP classes plus ArrayList save/load.
3. MainFrame: button handlers and JFileChooser setup.

Not included:
- H3 Polygon/Asteroids geometry.
- Timer/chronometer code.
